# Carbon Footprint Calculator


## Files
- `index.html` — page structure and content
- `style.css` — custom page styling

## Run locally
Open `index.html` in a web browser. An internet connection is needed to load Bootstrap and the environmental image.

## Publish with GitHub Pages
1. Create a **public** repository on GitHub (for example, `carbon-footprint-calculator`).
2. Upload `index.html`, `style.css`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your live URL will usually be:
   `https://YOUR-USERNAME.github.io/carbon-footprint-calculator/`
7. Open the live URL and check that the page and image load.

Replace `YOUR-USERNAME` with your GitHub username. Do not submit the example URL; submit the actual URL GitHub gives you.
